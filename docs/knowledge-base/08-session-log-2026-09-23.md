## Key decisions

- Randomize via Gmail dots, not `+` (form validation) and not disposable inboxes (OTP must be readable).
- CIMB Niaga VA is a hard requirement → code constant, not config.
- Reload-on-timeout only for idempotent GET pages; never after submit.
- CMS total compared to `subtotal − discount` (fee excluded) — confirmed from real data.
- Creator verification in a separate browser context.
